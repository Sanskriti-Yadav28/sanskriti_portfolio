# Projects

## Memora AI
Memora AI is an AI-powered smart gallery for memory retrieval: a photo gallery platform built for intelligent search, automated tagging and efficient image retrieval.
Tech: React, Redux Toolkit, LangChain, LangGraph, Gemini LLM, Node.js, Python, Supabase (pgvector), Docker, REST/SSE APIs.
Sanskriti engineered a responsive frontend architecture, optimized UI components and handled application-wide state management. She integrated dynamic frontend workflows with a sophisticated AI backend for intelligent search, automated tagging and image retrieval, and worked with backend and DevOps engineers to connect the UI to vector search and facial recognition.

## Pincode To Address
An interactive web utility that maps a user-provided pincode to detailed location data through public API integration.
Tech: HTML, CSS, JavaScript, public REST APIs.
She integrated public REST APIs to fetch, process and render accurate location details in real time.

## Weather Application
A responsive weather tracking interface that fetches and displays real-time meteorological data and forecasts based on user input.
Tech: HTML, CSS, JavaScript, third-party weather APIs.
She implemented asynchronous JavaScript functions to consume the weather APIs and render the data efficiently.
